<h1>🔐 Backend de Autenticação MVC</h1>
<h2>⚠️ Autenticação 100% desenvolvida à mão</h2>
<p>Todos os fluxos foram implementados diretamente na API, sem Firebase, Auth0, Clerk ou outro serviço pronto de autenticação.</p>

<h2>1. Projeto</h2>
<p>Backend com cadastro, login, envio de e-mail, verificação de conta por e-mail, recuperação de acesso e redefinição segura de senha.</p>
<p><strong>Tecnologias:</strong> Node.js, Express, JavaScript, MySQL, JWT, bcrypt, Nodemailer, variáveis de ambiente e arquitetura MVC.</p>
<h2>2. Como executar</h2>
<p><strong>Instalação:</strong> execute <code>npm install</code>, copie <code>.env.example</code> para <code>.env</code> e configure banco, JWT e serviço de e-mail.</p>
<p><strong>Banco:</strong> execute no MySQL os scripts disponíveis em <code>tabelas_em_sql</code> e depois inicie a API com <code>npm run dev</code>.</p>
<h2>3. Experiência</h2>
<p>Estrutura MVC organizada em models, controllers, services, routes e middlewares, acompanhada de uma animação futurista que representa código, segurança e autenticação.</p>
